#Portfolio Website

This repository contains a personal portfolio website built with React, Vite, and Tailwind CSS. The site is designed to showcase the profile, skills, services, and contact details for `Hamas Akram`.

## Project Overview

- **Framework:** React
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Animations:** AOS (Animate on Scroll), Framer Motion
- **Purpose:** Personal portfolio website with sections for Home, About, Services, and Contact.

## Key Features

- Responsive hero section with a personal profile photo
- Smooth navigation and section anchor links
- About section with profile description and skill badges
- Service cards for offering user-friendly digital services
- Contact section with visible email and phone details
- Clean modern UI with responsive layout and user interactions

## Project Structure

- `src/components/`: React components used across the portfolio
  - `Hero.jsx`
  - `About.jsx`
  - `Services.jsx`
  - `Contact.jsx`
  - `Navbar.jsx`
  - `Footer.jsx`
  - `Preloader.jsx`
- `src/assets/about/`: images used in the About and Hero sections
- `HCI_Report.md`: report describing the HCI techniques applied in the design

## Available Scripts

In the project directory, you can run:

### `npm install`
Install dependencies.

### `npm run dev`
Start the Vite development server.

### `npm run build`
Create a production build.

### `npm run preview`
Preview the production build locally.

## How to Use

1. Open a terminal in the project folder.
2. Run `npm install` if dependencies are not installed.
3. Run `npm run dev` to start the local development server.
4. Open the displayed URL in your browser (usually `http://localhost:5173/` or similar).
